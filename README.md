# 오늘우리

부모님께 이 순간의 감정을 전해보는 인터랙티브 웹사이트입니다. (실제로 전해지지는 않아요.)

기분 → 무엇을/어디서/누구와 → 확인 → 감정 카드 → 감정만큼 잔 채우기 → 원 그리기 → 캐릭터 선택 → 캐릭터 피드백 순서로 진행됩니다.

- 단계마다 조작 가이드가 나오고, 다음으로 갈 수 있으면 오른쪽 화살표가 깜박입니다.
- 배경음악과 효과음은 Web Audio로 직접 만들어서 별도 음원 파일이 없습니다. 왼쪽 위 버튼으로 끌 수 있습니다.
- 완료한 기록은 브라우저(localStorage)에 저장되고 시작 화면의 '기록보기'에서 볼 수 있습니다.

## 실행

```bash
python -m http.server 5173
```

브라우저에서 `http://localhost:5173` 을 열어주세요. 1700×1064 디자인 기준이며 화면 크기에 맞게 자동으로 확대/축소됩니다.

## 구성

- `index.html` — 화면 구조
- `style.css` — 스타일
- `script.js` — 화면 전환, 인터랙션, 사운드, 기록 저장
- `assets/` — 캐릭터·카드·배경 이미지 (Figma 디자인에서 추출)
