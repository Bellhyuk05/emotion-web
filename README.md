# 이 순간의 감정

부모님께 이 순간의 감정을 전해보는 인터랙티브 웹사이트입니다. (실제로 전해지지는 않아요.)

기분 → 무엇을/어디서/누구와 → 감정 카드 → 감정만큼 잔 채우기 → 원 그리기 → 하고 싶은 말 → 캐릭터 선택 → 캐릭터 피드백 순서로 진행됩니다.

## 실행

```bash
python -m http.server 5173
```

브라우저에서 `http://localhost:5173` 을 열어주세요. 1920×1080 디자인 기준이며 화면 크기에 맞게 자동으로 확대/축소됩니다.

## 구성

- `index.html` — 화면 구조
- `style.css` — 스타일
- `script.js` — 화면 전환과 인터랙션
- `assets/` — 캐릭터·배경 이미지 (Figma 디자인에서 추출)
